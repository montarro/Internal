# Photography brief — Turf and Landscaping

The site currently ships **branded WebP placeholders** so every image slot is
valid and fast. Replace each file below with a **real photograph**, keeping the
**exact same filename** so no HTML needs to change. Save as **WebP** (quality
~80), sized as noted. Keep alt text accurate to the real photo if the subject
changes — alt text lives in `index.html` and the generated pages.

## Shooting guidelines
- **Landscape orientation**, natural daylight, shot after clean-up (no tools,
  bins or hoses in frame).
- Show **finished work**: crisp lawn edges, swept paving, level walls.
- Get **before/after pairs** where you can — great for social and future pages.
- Get written consent if a client's house number or car is identifiable.
- **Real local jobs** beat stock every time; where a filename names a suburb,
  use a job from that suburb if possible.
