# Drop real photos here

Upload a photo named after its slot and the build converts it to an optimised
WebP under the right filename — no renaming or HTML changes needed.

| Upload as | Becomes | Used for |
| --- | --- | --- |
| `hero.jpg` | `hero-landscaping-northwest-melbourne.webp` | Hero background (1920×1080) |
| `og.jpg` | `og-turf-and-landscaping.webp` | Social share card (1200×630) |
| `turf.jpg` | `service-natural-turf-solutions.webp` | Natural Turf card + page |
| `paving.jpg` | `service-paving-and-stepping-stones.webp` | Paving card + page |
| `walls.jpg` | `service-retaining-walls.webp` | Retaining Walls card + page |
| `soft.jpg` | `service-soft-landscaping.webp` | Soft Landscaping card + page |
| `design.jpg` | `service-garden-design.webp` | Garden Design card + page |

For the 9 gallery shots, upload using the exact gallery filename with any
extension, e.g. `new-turf-lawn-craigieburn-backyard.jpg`.

Accepts `.jpg` `.jpeg` `.png` `.webp`. Images are centre-cropped to the ratio
the layout expects. See `../../PHOTOGRAPHY.md` for what to shoot.
